# Ecommerce Catalog App

Aplicação full stack de catálogo de produtos, desenvolvida para praticar 
integração entre backend .NET/C# e frontend React/TypeScript.

## Tecnologias
- Backend: .NET 8, C#, Entity Framework Core
- Frontend: React, TypeScript, Vite

## Funcionalidades
- Listagem de produtos
- Busca e filtro por categoria
